Installation

Installe RideNCT

Une vraie appli plein écran, installée depuis ton navigateur : pas de store, rien à télécharger. Aucun compte n'est demandé pour l'installer.

RideNCT est déjà installée

Ouvre-la depuis l'écran d'accueil de ton téléphone.

Sur iPhone

Safari est le navigateur recommandé (iOS 16.4 ou plus récent).

  1. Appuie sur le bouton ci-dessous pour ouvrir RideNCT.
  2. Touche Partager en bas de Safari.
  3. Choisis Sur l'écran d'accueil, puis Ajouter.
  4. Ouvre RideNCT depuis ton écran d'accueil.
Ouvrir RideNCT

Sur Android

Chrome, Edge, Samsung Internet et Firefox sont compatibles.

  1. Appuie sur le bouton ci-dessous pour ouvrir RideNCT.
  2. Touche Installer RideNCT. Si le bouton n'apparaît pas : menu ⋮ du navigateur, puis Installer l'application (ou Ajouter à l'écran d'accueil).
  3. Ouvre RideNCT depuis ton écran d'accueil.
Ouvrir RideNCT

Ouvre cette page dans ton navigateur

Le navigateur intégré (Instagram, Facebook, Messenger…) ne permet pas d'installer une appli. Copie le lien, ouvre ton navigateur habituel et colle-le.

RideNCT se vit sur ton téléphone

Elle utilise le GPS, le compteur et l'intercom : ouvre cette page depuis ton iPhone ou ton Android pour l'installer.

Compatibilité

  • iPhone / iPad : Safari (recommandé) ; Chrome et Edge depuis iOS 16.4.
  • Android : Chrome, Edge, Samsung Internet, Firefox.
  • Non compatibles : navigateurs intégrés aux autres applications, et Firefox sur iPhone.
